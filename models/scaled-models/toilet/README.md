# Toilet

Scale model at **1:20**, made of 4 printable pieces that need no supports. Pieces are joined with **glue**.

> Generated by the `fc-scaled-model` skill from `model.json`. Rebuilding overwrites
> this README, the FCStd and the 3MF files, so edit `model.json` instead.

## Pieces

Each piece has its own `.3mf`, already turned to its support-free print orientation.

| Piece | From part | Print orientation | Print size (mm) | File |
|---|---|---|---|---|
| Bowl | Bowl | upside down | 18 x 35 x 20 | `toilet-bowl.3mf` |
| Seat | Seat | as modelled | 18 x 25 x 2.5 | `toilet-seat.3mf` |
| Cistern1 | Cistern | as modelled | 22.5 x 10 x 18 | `toilet-cistern1.3mf` |
| Cistern2 | Cistern | as modelled | 23.5 x 11 x 2.5 | `toilet-cistern2.3mf` |

Parts split so they print without supports:

- Cistern1 (auto): `z <= (rim_h) + (tank_h)`
- Cistern2 (auto): `z >= (rim_h) + (tank_h)`
