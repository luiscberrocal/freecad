# Three Bedroom House

Single-floor house generated by `build_house.py` with the BIM workbench: 12 x 8.5 m
footprint, 150 mm block exterior walls, 100 mm block interior walls, slab on grade
and a 22 degree hip roof with metal sheeting.

## Rebuild

Edit the constants at the top of `build_house.py`, then run from the repo root:

```sh
/Applications/FreeCAD.app/Contents/Resources/bin/freecadcmd \
    models/bim/three-bedroom-house/build_house.py < /dev/null
```

This overwrites the generated files, so changes made by hand in the `.FCStd` are lost.

## Files

- `three-bedroom-house.FCStd`: native BIM model
- `three-bedroom-house.ifc`: IFC4 export
- `three-bedroom-house-plan.pdf`: floor plan, A3 at 1:50
- `three-bedroom-house-schedule.csv`: room, wall, door and window quantities

## Not modelled

Foundations, columns, ring beams, ceilings, rebar, roof framing, fixtures, furniture
and MEP services. This is a concept model, not a construction design.
