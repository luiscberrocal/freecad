| Faucet2 | Faucet | as modelled | 2.5 x 15.5 x 1.25 | `kitchen-double-sink-faucet2.3mf` |

Parts split so they print without supports:

- Cabinet1 (manual): `z <= hollow_top`
- Cabinet2 (manual): `z >= hollow_top`
- Faucet1 (auto): `z <= (counter_h + tap_base_h) + (neck_z - counter_h - tap_base_h)`
- Faucet2 (auto): `z >= (counter_h + tap_base_h) + (neck_z - counter_h - tap_base_h)`
