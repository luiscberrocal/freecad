# L-shaped sofa

Scale model at **1:20**, made of 8 printable pieces that need no supports. Pieces are joined with **glue**.

> Generated by the `fc-scaled-model` skill from `model.json`. Rebuilding overwrites
> this README, the FCStd and the 3MF files, so edit `model.json` instead.

Three-seat sofa with a right-hand chaise longue, separate seat and back cushions, left arm
