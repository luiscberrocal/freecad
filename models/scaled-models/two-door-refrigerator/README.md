## Plan

## Rebuilding

`build_two_door_refrigerator.py` rebuilds this model from `model.json` without the skill. It needs only
[uv](https://docs.astral.sh/uv/) and FreeCAD (`--help` lists the options):

```sh
uv run build_two_door_refrigerator.py
```

With the skill installed:

```sh
python3 ~/.claude/skills/fc-scaled-model/scripts/fc_scaled_model.py build two-door-refrigerator
```
